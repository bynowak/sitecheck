# Changelog

All notable changes are documented here. Versions follow semantic versioning. Breaking JSON schema or API changes require a major release.

## 1.0.0 — 2026-10-04

- Added independent TypeScript audit engine with metadata, accessibility, structure, technical, and discovery checks.
- Added DNS-pinned outbound transport, private-network blocking, bounded checks, and explicit skipped findings.
- Added Commander CLI with text/JSON reports, output files, and score-based exit codes.
- Added responsive Next.js dashboard with production API authentication, filters, and JSON exports.
- Added deterministic fixtures, CI, release automation, and community documentation.
